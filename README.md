# TensorGuild

TensorGuild enables distributed, parallel computation and auto-scaling for real-time data processing and optimized model orchestration.

TensorGuild is aimed at developers who need a straightforward, dependable solution.

**Highlights**

- TensorGuild enables distributed, parallel computation
- and auto-scaling for real-time data
- processing and optimized model orchestration

## Installation

1. Clone the repository: `git clone https://github.com/fuad403273/TensorGuild.git`
2. `cd TensorGuild`
3. Install in editable mode: `pip install -e .`

## Configuration

TensorGuild is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
